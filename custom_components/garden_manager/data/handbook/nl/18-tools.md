# Gereedschap en materialen

Goed gereedschap hoeft niet duur te zijn, wel degelijk en scherp. Koop liever één goede spade dan drie slechte. In de takenlijst toont Hortulus bij elke taak welk gereedschap en materiaal je nodig hebt; de **boodschappenlijst** (Advies › Benodigdheden) rekent uit wat je dit seizoen moet kopen.

## Basisuitrusting

| Gereedschap | Waarvoor | Tip |
|---|---|---|
| Spitvork / grelinette | grond losmaken zonder te keren | spaart je rug en het bodemleven |
| Spade | plantgaten, kanten afsteken | scherp houden met een vijl |
| Schoffel (trek- of duwschoffel) | onkruid wieden, korst breken | wekelijks bij droog weer |
| Hark | zaaibed fijn maken, mulch verdelen | |
| Plantschepje en pootstok | uitplanten, prei en uien | |
| Snoeischaar (bypass) | snoeien, oogsten | ontsmetten tussen planten |
| Gieter met fijne broeskop + tuinslang met sproeikop | zaaien en water geven | regenwater gebruiken |
| Kruiwagen of tuinkar | compost, mulch, oogst | |
| Plantlabels en een potlood | weten wat waar staat | potlood blijft leesbaar |
| Plantkoord / jute touw | aanbinden | |
| Zaaibakken, potjes, zaaigrond | voorzaaien | |
| Handschoenen, knielmat | | |

## Handig voor wie meer doet

- **Grondthermometer** - zaai pas als de grond warm genoeg is.
- **Min/max-thermometer** in de serre.
- **Bodemvochtmeter** of draadloze sensor (koppelbaar met Home Assistant).
- **Zaaiplank / zaaitouw** voor rechte rijen, **rijenmaker**.
- **Kweeklamp en verwarmingsmat** voor het voorzaaien.
- **Takkenschaar en snoeizaag** voor fruitbomen; **ladder met drie poten** voor de oogst.
- **Druppelslang en timer** (of irrigatie via Home Assistant).
- **Compostzeef** en een **compostthermometer**.

## Materialen per seizoen

| Materiaal | Wanneer | Hoeveel (vuistregel) |
|---|---|---|
| Compost | voorjaar en najaar | 3-5 l/m² per jaar (± 2-3 kg) |
| Organische meststof (korrels) | voor zware eters | 50-100 g/m² |
| Kalk (dolomiet) | om de 3 jaar bij pH < 6 | 100-200 g/m², nooit samen met mest |
| Vliesdoek (17-30 g/m²) | vorst, vroege teelt, insecten | bedbreedte + 50 cm |
| Insectengaas (0,8 mm) | kolen, wortelen, uien | bedbreedte + 60 cm |
| Schaduwdoek 30-40 % of schaduwkalk | serre, slaatjes bij hitte | dakoppervlak |
| Stro of grasmaaisel | mulch | 5-8 cm laag |
| Bamboestokken, tomatenspiralen | bonen, tomaten | 1 per plant |
| Vogelnet | fruit, koolzaailingen | fijne maas |
| Groenbemestingszaad | najaar | 2-3 g/m² (phacelia), 15-20 g/m² (rogge) |

## Zelf bemesting en middeltjes maken

| Wat | Recept | Gebruik |
|---|---|---|
| Brandnetelgier (stikstof) | 1 kg jonge netels in 10 l regenwater, 10-14 dagen gisten | 1:10 voor bladgewassen, 1:20 voor zaailingen |
| Smeerwortelgier (kalium) | 1 kg blad in 10 l water, 3 weken | 1:10 voor tomaat, courgette, fruit |
| Compostthee | schep rijpe compost in een jutezak, 3 dagen in een ton regenwater | onverdund gieten |
| Houtas (kalium, kalk) | as van onbehandeld hout | 50-100 g/m², niet bij aardappel (schurft) |
| Koffiedik | uitgespreid, gedroogd | licht zuur, voor blauwe bes; wormen houden ervan |
| Eierschalen | gedroogd en fijngemalen | kalk, rond kolen; grof tegen slakken |
| Urine (verdund) | 1:10 met water, vers | rijk aan stikstof, op de grond, niet op blad |
| Grasmaaisel | dunne lagen | mulch en langzame stikstof |
| Bladaarde | bladeren 1-2 jaar laten vergaan | zaaigrond, bodemverbeteraar |

## Onderhoud van gereedschap

Na elk gebruik: aarde eraf borstelen en drogen. Eén keer per jaar (november): slijpen, roest verwijderen met staalwol, metaal licht oliën en houten stelen insmeren met lijnolie. Ontsmet snoeischaren tussen zieke planten met alcohol.
